# evanli.org

Vite + React + TypeScript. Read `BRIEF.md` before changing anything.

- Content: `src/data.ts`. Posts: `src/posts/*.md` (frontmatter `title`, `date`, `draft`).
- Diagrams: `src/diagrams/specs.ts`, rendered by `src/diagrams/Diagram.tsx`.
- Brand images: edit `brand/*.svg`, then `npm run brand` to regenerate the PNGs.

```
npm install
npm run dev
```
